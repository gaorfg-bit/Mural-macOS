# Security policy

## Supported versions

Security fixes target the latest published Mural macOS release and the `main`
branch. Earlier releases are not maintained separately. Please use the
[latest release](https://github.com/gaorfg-bit/homebrew-mural/releases/latest)
when checking whether an issue still occurs.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/gaorfg-bit/Mural-macOS/security/advisories/new).
A GitHub account is required. Do not disclose an unpatched vulnerability in a
public issue, discussion, or social media post.

Include:

- The Mural version, macOS version, and Mac architecture.
- A description of the issue and its possible security impact.
- Steps to reproduce it, preferably with synthetic images or a minimal example.
- Relevant logs or a proof of concept, with private information removed.

Do not send credentials, personal images, or unredacted logs containing private
file paths. Test only on systems and files you own or have permission to use.

The maintainer will review the report, discuss reproduction and impact with you,
and coordinate a fix and disclosure when appropriate. This is an independent
project; no fixed response or resolution time is guaranteed.

## Other bugs and questions

For ordinary bugs, feature requests, and installation questions, use the
[public issue tracker](https://github.com/gaorfg-bit/homebrew-mural/issues).
Review attachments for private information before posting.
